# ✊✋✌️ Stone-Paper-Scissors Game  
### Created by Sanskriti Sourya

A classic **Stone-Paper-Scissors** game built using **HTML**, **CSS**, and **JavaScript**. This fun web-based game allows the user to play against the computer with real-time score tracking and clean interactive UI.

## 🎮 Game Overview

The game lets players select between Stone 🪨, Paper 📄, or Scissors ✂️. The computer randomly picks its choice, and the winner is decided based on traditional game rules:

- **Stone** crushes **Scissors**
- **Scissors** cuts **Paper**
- **Paper** covers **Stone**

---

## 🛠️ Technologies Used

- **HTML5** – For structure and layout
- **CSS3** – For styling and responsive design
- **JavaScript (ES6)** – For dynamic logic and game interactivity

---

## 🚀 Features

- 🎲 Randomized computer choice
- 🧠 Real-time game logic and result display
- 📊 Scoreboard for user vs computer
- 🎨 Fully responsive design
- 🔄 Restart option for a fresh game

2. Navigate to the project directory:
   ```bash
   cd stone-paper-scissors
   ```
3. Open `index.html` in your web browser to play.
